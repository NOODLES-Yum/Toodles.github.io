# Toodles

Toodles is a cheerful little personal website hosted on [GitHub Pages](https://pages.github.com/).

## How to View

Visit: `https://toodles.github.io`

## Features

- Simple and colorful HTML/CSS layout
- Easy to customize
- MIT License included

## Usage

1. Clone or download this repository.
2. Update `index.html` with your own content.
3. Push to GitHub.
4. Your site will automatically be live on GitHub Pages.
